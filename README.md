# Grow

## État du dépôt

Le projet est en phase initiale de restructuration, hors du contexte du
Datathon PolyFinances 2026 pour lequel il a été créé.

- **La documentation restante n'est pas à jour** : elle décrit un état
  antérieur du dépôt (contrat d'API, `infra/`, documentation du défi) qui
  a depuis été supprimé ou déplacé.
- **La version courante n'est pas fonctionnelle** pour la même raison :
  les dépendances, la configuration d'exécution et le déploiement ne sont
  pas encore rétablis dans la nouvelle structure.

Ces deux avertissements seront retirés quand la restructuration sera
terminée.
